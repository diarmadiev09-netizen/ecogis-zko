# ЭкоГИС ЗКО

Веб-ГИС мониторинга экологического состояния Западно-Казахстанской области.
Авторы: Қолқанат, Дияр, Аслан.

**Сайт:** https://diarmadiev09-netizen.github.io/ecogis-zko/ · **Код:** https://github.com/diarmadiev09-netizen/ecogis-zko

Карта в стиле Europa Universalis IV: районы раскрашиваются по выбранному показателю (эко-индекс, воздух, вода, почва, растительность, осадки), есть хронология по месяцам, тревоги при превышении порогов, рейтинг районов, предприятия I категории и ИИ-помощник. Интерфейс на русском и казахском.

Сайт полностью статический: ни сервера, ни базы данных. Всё, что он показывает, лежит в `web/data.json`.

## Структура

```
web/index.html           страница
web/app.js               карта, режимы, хронология, тревоги, рейтинг
web/chat.js              ИИ-помощник (Claude, OpenAI, Gemini и др., прямо из браузера)
web/i18n.js              тексты на русском и казахском
web/style.css            оформление
web/data.json            границы районов, станции, предприятия, помесячные измерения
tools/generate_seed.py   пересобирает data.json
.github/workflows/pages.yml   публикация папки web на GitHub Pages
```

## data.json

| Раздел | Что внутри |
|---|---|
| `districts` | GeoJSON: 12 районов (geoBoundaries, CC BY 4.0) и условный контур г. Уральска (круг 9 км), названия и источники воздействия на русском и казахском |
| `stations` | 17 станций мониторинга (lon/lat, район) |
| `enterprises` | 14 предприятий I категории ЗКО по данным ecokarta.kz (известен только район) |
| `monthly` | средние по району за месяц: `aqi`, `wpi` (ИЗВ), `soil` (% деградации), `ndvi`, `precip` (осадки, мм) |

**Измерения сейчас синтетические** — их генерирует `tools/generate_seed.py` с правдоподобными сезонными закономерностями. Реальные значения можно вписать прямо в `monthly` (строка на район, месяц и показатель) или изменить генератор. Откуда брать реальные данные — в окне «Источники данных» на сайте.

Пересобрать файл:
```
python tools/generate_seed.py geoBoundaries-KAZ-ADM2_simplified.geojson
```
Исходник границ: [geoBoundaries KAZ ADM2](https://github.com/wmgeolab/geoBoundaries/raw/main/releaseData/gbOpen/KAZ/ADM2/geoBoundaries-KAZ-ADM2_simplified.geojson). В нём старые названия: Зеленовский = Байтерекский, Урдинский = Бокейординский.

Эко-индекс (0–100) считается на сайте из AQI, ИЗВ, деградации почв и пикового NDVI; осадки в него не входят — это климатический фон, а не загрязнение.

## ИИ-помощник

Кнопка «ИИ-помощник» открывает чат. Он работает прямо в браузере, без сервера: посетитель выбирает сервис ИИ и вставляет **свой** ключ API. Ключ хранится только в его браузере (localStorage) и отправляется только выбранному сервису; запросы оплачиваются с аккаунта владельца ключа. «Забыть ключ» удаляет его из браузера.

| Сервис | Как подключается | Модель |
|---|---|---|
| Claude (Anthropic) | официальный SDK `@anthropic-ai/sdk` 1.0.0 | `claude-opus-5-5` |
| OpenAI, Google Gemini, OpenRouter, Groq, DeepSeek, Mistral | OpenAI-совместимый API (`/chat/completions` с вызовом функций) | выбирается из списка, который сайт получает у сервиса (`/models`) |
| Другой | любой OpenAI-совместимый адрес API, который разрешает запросы из браузера (CORS) | вписывается вручную |

Все перечисленные сервисы проверены: они разрешают запросы со страницы на GitHub Pages. Для работы нужна модель, которая умеет вызывать функции (tools).

Какой бы сервис ни был выбран, ИИ читает данные карты через одни и те же инструменты:

| Инструмент | Что делает |
|---|---|
| `list_districts` | районы, станции, предприятия, доступные месяцы |
| `get_monthly_data` | помесячные значения с фильтрами по району, показателю и периоду |
| `find_stations_near` | станции в радиусе от точки (расстояние по большому кругу) |
| `show_on_map` | переключает на сайте район, режим карты и месяц — карта показывает то, о чём ответ |

Помощник отвечает на языке вопроса и предупреждает, что измерения демонстрационные. Для Claude включён резервный режим: если запрос отклонят фильтры безопасности, его выполнит запасная модель (`fallbacks: "default"`).

Не вводите свой ключ на чужом или общем компьютере. Ключи в код и в репозиторий не добавляйте: репозиторий публичный.

## Запуск на своём компьютере

```
cd web
python -m http.server 8000
```
и откройте http://localhost:8000 (с диска как файл страница не загрузит `data.json`).

## Публикация

Сайт публикуется на GitHub Pages автоматически: при каждом изменении папки `web` в ветке `main` срабатывает `.github/workflows/pages.yml`.
